# 안내판 판독 응답 시간과 정확도

CPU 서버에서 사진 한 장을 반복 제출했을 때 응답 시간 중앙값은 **630.2ms에서 190.9ms**로 줄었다. 이전 시험에서 놓친 네 역의 방면을 추가로 읽었다. 이번 수정에 쓰지 않은 사진 25장에서는 사람이 방면을 채점한 15장 중 두 버전 모두 6장을 맞혔다.

## 응답 시간

| 로컬 HTTP 응답 시간 | 이전 버전 | 개선 버전 |
| --- | ---: | ---: |
| 중앙값 | 630.2ms | 190.9ms |
| 95백분위수 | 866.5ms | 428.6ms |

이전 버전은 요청마다 Python과 OCR 모델을 새로 시작했다. 개선 버전은 요청이 끝나면 사진을 해제하고 모델이 준비된 프로세스를 다음 요청에 재사용한다. 두 요청까지 동시에 처리하며 5분간 유휴 상태인 프로세스는 종료한다.

동일 호스트에 두 버전을 띄우고 각각 예열 요청 한 번을 보낸 뒤 새 사진 25장을 두 차례씩 제출했다. 매 회차 사진 순서를 섞고 사진마다 먼저 실행하는 버전을 번갈아 바꿨다. 한 번에 한 요청만 실행했다. 버전마다 50개의 왕복 시간을 측정했으며, 업로드 바이트와 응답 JSON을 대조했다. 수치는 CPU와 로컬 네트워크에서 연속 요청을 보낸 결과다. 첫 요청의 모델 로딩과 모바일 통신에 걸리는 시간은 별도 항목이다.

## 실제 사진의 방면 판정

| 시험 조건 | 개선 전 | 개선 후 |
| --- | ---: | ---: |
| 이전 33장 중 방면을 읽을 수 있던 사진 | 8/23 | 12/23 |
| 새 사진 · 가로로 나란한 세 역 | 6/10 | 6/10 |
| 새 사진 · 위아래 배치, 한쪽 이웃, 분기 표지 | 0/5 | 0/5 |
| 새 사진 · 방면 없음 또는 미지원 노선에서 올바르게 보류 | 10/10 | 10/10 |

기존 사진 중 까치산은 **← 신정**, 송정은 **← 마곡**, 구일은 **← 개봉**을 추가로 맞혔다. 세 표지 모두 굵은 화살표 윤곽을 주변 밝기에서 분리해 찾았다. 개봉은 현재역 아래 짧은 파란 띠의 화살촉을 찾아 **→ 오류동**을 맞혔다. 기존 시험의 81장 전체를 사진 선택 화면에서 다시 제출했고, 이전의 정답이 오답이나 보류로 바뀐 사례는 없었다. [까치산 촬영 원문](https://platfrom.tistory.com/entry/까치산역서울) · [구일 촬영 원문](https://tjo4183.tistory.com/465) · [개봉 촬영 원문](https://tjo4183.tistory.com/466)

독립 시험은 앞선 시험과 원본 해시가 겹치지 않는 두 촬영자의 사진 25장을 사용했다. 결과를 보기 전에 눈으로 읽은 노선·현재역·화살표·방면을 기록하고, 네 값이 모두 맞아야 정답으로 셌다. 신녕·영주처럼 지원 노선 밖에서 찍은 표지는 보류 대상으로 분류했다. 앱에서 고른 원본과 이전 API에 제출한 파일의 전송 해시도 비교했다. 15장의 방면 중 6개는 맞혔고 9개는 보류했다. 이번 표본에서 잘못 표시한 방면은 0건이다. 삼성의 위아래 배치와 봉은사의 점선 화살표, 옛 수인선 신포·숭의의 번호는 여전히 보류됐다.

작은 역명은 서버에 도착한 원본에서 해당 영역을 다시 잘라 읽도록 했다. 회전 정보가 있는 사진에서도 영역이 일치하고 축소본에서 사라진 획이 OCR 입력에 남는 것을 회귀 시험으로 확인했다. 이 변경만으로 실사진의 최종 정답이 늘어났다는 결과는 확보하지 못했다. 실시간으로 이동하며 촬영한 영상의 정확도도 이번 정지 사진 시험에서 측정하지 않았다.

## 실행 환경과 재현

사용한 모델은 한국어 PP-OCRv5 모바일, 실행 환경은 RapidOCR 3.10.0과 ONNX Runtime 1.32.0이다.

사진별 원문과 본문 이미지 순번, 원본·업로드 SHA-256, 두 버전의 응답, 두 회차의 실측 시간, 판독 코드 해시를 함께 기록했다. 같은 원본을 **AR 카메라 → 안내판 읽기 → 사진 선택**에서 고르면 화면 결과를 비교할 수 있다. 서버 응답 시간은 JSON의 `upload_sha256`과 일치하는 파일을 아래처럼 제출해 확인한다. [사진별 시험 기록](2026-11-20-performance-results.json) · [직전 시험 기록](2026-11-20-improved.md)

```bash
curl -sS -w '\n%{time_total}s\n' -F 'images=@station.jpg;type=image/jpeg' \
  http://localhost:8080/api/signs/recognize
```
